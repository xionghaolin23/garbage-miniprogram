# 帮你扔 · 微信小程序

原生微信小程序（JavaScript + WXML + WXSS），独立工程，对接旁边的 `garbage-service` Java 后端。无需安装前端框架或构建 npm 依赖，导入微信开发者工具即可继续开发。

## 已完成页面

首页预约、订单列表、订单详情、我的、登录、家庭地址、月卡购买/续费、固定代扔计划、服务规则与隐私说明、联系客服、小区入驻申请，共 11 个页面。底部三个 Tab：首页 / 订单 / 我的。

使用浅米色背景、绿色卡片与清晰的大按钮。首页默认今天，可切换今天起 7 天内日期，同时勾选中午/晚上，展示已预约 X / 100 户、待支付占位、截止及满额状态和所选日期已有任务；订单详情展示履约、取消和退款进度；月卡页展示实际服务日期。

## 本地运行

1. 启动后端：

```sh
cd /Users/xionghaolin/java/code/garbage-service
./mvnw spring-boot:run
```

2. 打开微信开发者工具，导入目录：

```text
/Users/xionghaolin/java/code/garbage-miniprogram
```

3. 工程配置中的 `miniprogramRoot` 已指向 `miniprogram/`。当前 AppID 为占位值 `touristappid`；可在工具中选用自己的测试号或替换为自己的小程序 AppID。游客项目可用能力以工具当前版本为准，真机调试需使用自己的有效 AppID。
4. 本地调试开启“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。工程 `urlCheck` 默认关闭，仅用于本地调试。
5. 编译后进入首页，点击登录，输入联调家庭名称，例如“张三家”，再登记地址。同一个家庭名称会进入同一个测试账号。
6. 本地后端默认示例小区为阳光花园。单次预约仍受真实北京时间截止限制；晚上截止后可切换未来日期预约。

初始配置在 `miniprogram/config.js`：

```js
module.exports = {
  mode: 'local',
  baseUrl: 'http://127.0.0.1:8086',
  serviceName: '帮你扔',
  customerServicePhone: '',
  customerServiceWechat: '',
  subscribeTemplateId: '',
  requestTimeout: 12000
};
```

本地模式明确显示“模拟支付，不会实际扣款”。首次运行不需要填写 AppSecret、商户密钥或支付证书，这些机密也不应放在小程序源码里。

## 业务行为

- 一名用户一个家庭，地址首次登记后只能查看，修改入口转客服。
- 单次默认每场 ¥3（以后台当前售价为准），可同时选两场。截止前已支付订单按场次取消退款，截止后按钮关闭，最终由后端校验。
- 月卡默认 ¥75 / 30 个自然日，每天一次，默认晚上场，首购或过期重购次日生效，续费顺延。未生效月卡不抵扣今天的单次服务，但可用于预约其有效期内的未来日期，当天超出月卡次数按单次付费。
- 固定计划支持中午、晚上独立开关、放置位置与备注，滚动预留一周内名额；跳过从对应日期订单操作。
- 订单列表包含全部、待支付、待取走、已完成、取消/异常；支持分页与下拉刷新。筛选作用于已加载订单，可继续加载更多。
- 下单前持久化请求号；网络失败、支付取消或页面退出后可以继续原购买请求。切换账号或服务地址不会串用请求记录。
- 微信前端支付成功不是预约确认依据，支付后查询后端状态；关闭、处理中和退款分别提示。
- 使用北京时间并参考响应 HTTP Date 校准设备时间；数据库带小数秒的支付到期时间也可正确解析。
- 联系方式未配置时展示真实的“尚未开放”说明，不使用虚构号码。

## 测试

Node.js 18+，无需 `npm install`：

```sh
cd /Users/xionghaolin/java/code/garbage-miniprogram
npm run check
npm run check:native
npm test
npm run test:integration
```

`check` 检查 JSON、JavaScript、页面四件套、WXML 标签结构、路由及事件绑定，不替代微信 WXML 编译。

集成测试通过实际小程序 request/api/checkout 模块调用独立 Java 测试进程，使用临时内存 H2，不接触后端正常数据库；运行后自动关闭服务。默认使用相邻后端的 `target/garbage-service-0.1.0.jar`，可用 `BACKEND_JAR` 指定路径。该测试预约明天场次，不受当天截止时间限制。

当前验证：46 项逻辑测试、11 页静态检查、官方 WCC/WCSC 对 13 个 WXML 和 14 个 WXSS 文件的离线编译、44 组原生模板渲染检查，以及真实 Java HTTP 联调均已通过。

`check:native` 首次联网下载并校验官方 miniprogram-ci 2.1.31 的发布包，仅使用其中的本地编译器，不上传、不预览、不需要私钥。工具缓存保存在 .tools/，已加入 Git 忽略；当前原生编译脚本支持包内提供的 macOS/Windows 编译器，本次验证环境为 macOS ARM64。

本机未安装微信开发者工具，因此尚未完成开发者工具完整模拟器运行和真机验收。离线编译与模板渲染检查不等同于真实微信运行环境验收。

## 正式微信接入

当前后端仍为本地模拟登录、支付、退款、消息，因此本工程不能直接作为正式收款小程序发布。前端保留真实微信模式的调用入口，尚待真实后端实现及联调。

正式接入所需接口、配置与验收步骤见 `docs/INTEGRATION.md`；页面对应业务见 `docs/PAGES.md`。

工程内没有小程序 AppSecret、商户密钥或后台管理令牌。`local` 模式拒绝体验版与正式版使用，避免发布后继续模拟收款。正式模式不回退到本地模拟。

## 日期预约更新

需同时更新并重启 `garbage-service` 后端，再在微信开发者工具重新编译。不需重建或重新导入业务数据；后端启动新增价格配置和权益快照表。不会修改 `config/mysql.yml` 的账户密码。

首页人数每 15 秒刷新，也支持下拉刷新；日期切换会重新获取人数并清空所选场次。查询失败时阻止提交。未确认支付的预约恢复原日期和请求号，避免重复下单。上限按家庭计数，已预约人数包含固定计划，待支付占位另行展示；最终以提交时后端校验为准。

## 后台可配置价格

管理后台在后端 `http://127.0.0.1:8086/manage/index.html`，可以改日常价格、月卡每日次数、优惠价和活动时间。小程序通过公开 `/api/catalog` 读取价格，访客首页、会员页、规则页也使用配置价。下单携带展示的报价，价格改变需重新确认。

每天一次的新月卡成功购买后自动预留晚上；在“固定计划”中可改为中午。第二场可单独付费，已有月卡保留购买时的每日次数。退款提示和退款金额使用该场实付金额。

## 找不到小区时申请入驻

“我的家庭地址” → “所在小区”右上角“小区未入驻？申请开通”进入申请页。支持提交小区名称、城市、详细地址和可选联系方式，确认后查看审核进度；网络失败保留原请求号，可继续确认。

后台在 `/manage/index.html` 的“小区入驻审核”处理申请。审核通过后，返回家庭地址页或下拉刷新即可看到新小区；审核驳回时申请页显示原因。用户不会直接创建已开放的小区。

此次升级需同时更新并重启后端，再重新编译小程序。后端只新增申请及审核锁表，不修改已有业务数据。
